Sintaxe Linguagem C++ para Arduino

Estrutura Básica:

void setup() {
	// Código executado uma única vez ao ligar o Arduino
}

void loop() {
	// Código executado repetidamente em ciclo contínuo
}

Configuração Inicial (setup):

pinMode(pino, modo);

pino: número do pino digital;

modo: INPUT, OUTPUT ou INPUT_PULLUP.


Serial.begin(velocidade);

velocidade: 9600, 115200, etc.

Entrada e Saída Digital:

digitalWrite(pino, sinal);

pino: número do pino digital;

sinal: HIGH ou LOW.


var = digitalRead(pino);

var: variável do tipo bool (ou int) que receberá o sinal do pino;

pino: número do pino digital.

Entrada e Saída Analógica:

var = analogRead(pino);

pino: número do pino analógico (ex: A0);

var: variável do tipo int que receberá o valor lido (0 a 1023).


analogWrite(pino, valorPWM);

pino: número do pino digital com suporte a PWM (ex: 3, 5, 6, 9, 10, 11);

valorPWM: valor de 0 a 255.

Entrada e Saída de Strings pela Serial:

var = Serial.available();

var: variável do tipo int que receberá a quantidade de caracteres disponíveis na Serial.


Serial.print(dado);
Serial.println(dado);

Imprime o dado no monitor Serial (println adiciona quebra de linha).


var = Serial.readString();

var: variável do tipo String que receberá o conteúdo lido da Serial.

Tipos de Dados:

int float char bool String void

Declaração de Variáveis:

tipo nome ;
tipo nome = valorInicial ;

tipo: tipo de dado;

nome: nome da variável.

Atribuição:

variável = expressão ;

Definição de Constantes:

const int nome = valor ;

nome: nome da constante;

valor: valor da constante.


#define NOME VALOR

NOME: nome da constante;

VALOR: valor da constante.

Operadores:

+  -  *  /  %

==  !=  >  >=  <  <=

!	&&	||
not	and	or 

++  --  +=  -=

Estruturas de Decisão:

if (condição1) {
	comandos1
}
else if (condição2) {
	comandos2
}
else if (condição3) {
	comandos3
}
else if (condiçãoN) {
	comandosN
}
else {
	comandos padrão
}



switch(variável) {
	case constante1:
		comandos1
		break;

	case constante2:
		comandos2
		break;

	case constante3:
		comandos3
		break;

	default:
		comandos padrão
		break;
}

variável: a variável a ser comparada com as constantes;

constante1, constante2, …: as constantes a serem comparadas com a variável.

Estruturas de Repetição:

for(var = ini; var <= fim;  stream var++) {
	trecho de repetição
}

var: variável de contagem;

ini: valor inicial para a contagem;

fim: valor final para a contagem.


while(condição) {
	trecho de repetição
}



do {
	trecho de repetição
} while(condição);

Declaração de Vetores de Uma Dimensão:

tipo nome [tamanho];
tipo nome [tamanho] = { valor0, valor1, ... } ;

Acesso e Atribuição em Vetores:

nome [ índice ] = expressão ;
variável = nome [ índice ] ;

índice: posição do elemento no vetor (varia de 0 até tamanho - 1).

Temporização:

delay(tempo);

tempo: tempo de pausa em milissegundos.


delayMicroseconds(tempo);

tempo: tempo de pausa em microssegundos.

Definição de Função com Retorno de Valor:

tipo nomeDaFuncao(argumento1, argumento2, ..., argumentoN) {
	comandos
	return valor;
}

Definição de Função sem Retorno de Valor:

void nomeDaFuncao(argumento1, argumento2, ..., argumentoN) {
	comandos
}

Protótipo de Função:

tipo nomeDaFuncao(argumento1, argumento2, ..., argumentoN);
void nomeDaFuncao(argumento1, argumento2, ..., argumentoN);
